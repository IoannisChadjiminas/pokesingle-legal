# PokeSingle legal pages

Static HTML and CSS for the PokeSingle privacy policy, terms of service, and support page.

- Privacy: https://ioannischadjiminas.github.io/pokesingle-legal/privacy/
- Terms: https://ioannischadjiminas.github.io/pokesingle-legal/terms/
- Support: https://ioannischadjiminas.github.io/pokesingle-legal/support/

Hosted with GitHub Pages from `main`, repository root. No build, JavaScript, or third-party assets are needed. Keep `.nojekyll`. Pages must remain publicly accessible without signing in.

To preview locally, run `python3 -m http.server 8765 --directory legal-site` from the app repository, or `python3 -m http.server 8765` from this repository.

Update the effective/updated dates when materially changing the documents. Review content against the actual release configuration and operator details before each release. App-store privacy answers are maintained separately from these pages.
